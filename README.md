# Français

## Tamriel Ledger

Tamriel Ledger est un addon de statistiques long terme pour The Elder Scrolls Online.

Son objectif est de construire un véritable registre d’aventure à travers vos actions dans Tamriel.

L’addon enregistre vos statistiques :

- par personnage,
- au niveau du compte,
- de manière persistante,
- organisées par catégories.

Tamriel Ledger ne cherche pas simplement à afficher des chiffres.

Il cherche à raconter l’histoire de votre aventure.

## Installation

1. Téléchargez le projet
2. Placez le dossier `TamrielLedger` dans :

```txt
Documents/Elder Scrolls Online/live/AddOns
```

3. Activez l’addon en jeu

## Tamriel Ledger

Tamriel Ledger is a long-term statistics addon for The Elder Scrolls Online.

Its goal is to build a true adventure ledger through your actions across Tamriel.

The addon tracks statistics :

- per character,
- account-wide,
- persistently over time,
- organized by categories.

Tamriel Ledger is not just about displaying numbers.

It aims to tell the story of your adventure.

---

## Current Features

### V0.0.1 — Foundations

- Thieves Troves tracking
- Chest tracking :
  - Simple
  - Intermediate
  - Advanced
  - Master
- Statistics :
  - per character
  - account-wide
- Draggable UI
- UI toggle
- FR/EN translations
